# Conduct of Inquiry I Lab (SPA 096)

This repository contains teaching materials for the Conduct of Inquiry I Lab course.

## Course Materials

- `SPA_096_Conduct_of_inquiry_Lab.pdf`: Lab syllabus and overall guide.
- `Lab1b.R`: Introductory R script used in early sessions.

## Session Structure

Materials are organized in teaching order:

- `Session 0`: Setup and intro to R/RStudio
- `Session 1`: Basic R operations and data handling
- `Session 2`: Introduction to `dplyr`
- `Session 3`: Basic Stata operations and data manipulation
- `Session 4`: R practice
- `Session 5`: Aggregating and reshaping data
- `Session 6`: Reporting tables and results
- `Session 7`: Review exercises
- `Session 8`: Plots in R (`ggplot2`)
- `Session 9`: Graphing and Stata exercise
- `Session 10`: EDA exercise and project workflow
- `Session 11`: Prediction and advanced practice
- `Session 12`: Semester review materials

## Teaching Notes

- Each session folder may include `.Rmd`, `.do`, and data files.
- Run scripts from inside the relevant session folder to keep relative paths working.
- Temporary/local system files are ignored via `.gitignore`.
